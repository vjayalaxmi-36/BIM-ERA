DAY-1 Tasks:
      This Python program collection is designed for beginners to practice conditional statements and logical operators. It includes 30 simple tasks based on real-life situations such as login verification, eligibility checking, temperature validation, and student result analysis. The programs use `if`, `else`, `and`, `or`, and `not` operators to make decisions based on user input. These exercises help improve understanding of comparison operators and decision-making concepts in Python. Overall, it is a useful Day-1 practice set for building strong programming basics.
      
DAY-2 Tasks:
      This Day-2 Python task collection focuses on advanced conditional statements using multiple conditions with `if`, `elif`, and `else`. The programs are based on practical scenarios such as promotion eligibility, login systems, scholarship approval, loan verification, shopping discounts, and security systems. These tasks help learners understand how to combine logical operators and make complex decisions in Python. The exercises improve problem-solving skills and strengthen knowledge of user input handling and conditional logic. Overall, it is a useful practice set for building confidence in Python decision-making programs.
